# Broken Compass Tooltip

A Fabric Minecraft mod that adds client-side tooltips for broken lodestone compasses:

![A Minecraft screenshot of an inventory. A lodestone compass is hovered. Its tooltip says "Broken."](.github/assets/screenshot.png)

This allows you to differentiate between broken compasses and ones pointing to other dimensions, as they both spin randomly:

![A gif of a Minecraft inventory. Multiple lodestone compasses are hovered in sucession. Two are named "Overworld," two "Nether." One overworld compass is spinning randomly, while both Nether compasses are. The spinning overworld compass displays a "Broken" tooltip, but only one of the Nether ones does.](.github/assets/multiple.gif)

## Dependencies

- [Fabric Loader](https://fabricmc.net)
- [Fabric API](https://modrinth.com/mod/fabric-api)

## Installation

Jars are available on [Modrinth](https://modrinth.com/mod/broken-compass-tooltip) or [GitHub Releases](https://github.com/tommy-mitchell/broken-compass-tooltip/releases/latest).
